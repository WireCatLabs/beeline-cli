# beeline: звонки Билайн Облачной АТС на вашем компьютере

`beeline` копирует записи звонков из Облачной АТС Билайн, расшифровывает их прямо на вашем компьютере и показывает
каждый звонок как диалог менеджера и клиента. Записи и расшифровки никуда не отправляются. Подключите ИИ-агента, и он
найдёт нужный разговор и перескажет его.

Полное описание на английском: [README.md](README.md).

## Что нужно

- Компьютер с Linux. На macOS и Windows `beeline` должен работать, но там расшифровку ещё не проверяли.
- Node.js 22.16 или новее в ветке 22, либо 24 и новее. Если его нет, поставьте версию LTS с
  [nodejs.org](https://nodejs.org/ru/download).
- Ключ API от Облачной АТС. Его выдаёт личный кабинет Билайн: «Услуги» → «Интеграция по API».
- В АТС должна быть включена запись разговоров для менеджеров. Звонок без записи `beeline` не увидит.

## Установка

```sh
npm install -g @wirecat/beeline-cli
beeline doctor
```

`doctor` проверяет, что всё на месте, и говорит, что исправить.

## Первые шаги

`work` в командах ниже это имя профиля, одной АТС. Выберите любое и пишите его первым словом.

1. Войдите. Команда спросит ключ API, скрыв ввод, проверит его в Билайн и сохранит в системном хранилище ключей.

   ```sh
   beeline work session start
   ```

2. Скопируйте звонки. Первый раз берутся последние 30 дней, потом только новые.

   ```sh
   beeline work meetings sync
   ```

3. Скачайте модель распознавания речи. Это нужно один раз.

   ```sh
   beeline models download gigaam-v3
   ```

4. Расшифруйте звонки. Без условий берутся новые звонки от пяти секунд, самые свежие первыми, до 20 за раз.

   ```sh
   beeline work meetings transcribe
   ```

5. Посмотрите звонки и прочитайте один.

   ```sh
   beeline work meetings list
   beeline work meetings transcript 42
   ```

   `42` здесь номер звонка из списка.

6. Найдите слово во всех расшифровках.

   ```sh
   beeline work search meetings "доставка"
   ```

## Много звонков сразу

Одна команда расшифровывает не больше `--max-meetings` звонков. Чтобы разобрать сотни старых звонков, дайте большое
число или запустите команду несколько раз: каждый запуск продолжает с того места, где остановился прошлый. На
современном ноутбуке звонок расшифровывается примерно за седьмую часть его длины: 1644 секунды записи за 222 секунды.

```sh
beeline work meetings sync && beeline work meetings transcribe --max-meetings 500
```

Встроенного расписания пока нет. Чтобы звонки подтягивались сами, поставьте эту строку в cron или таймер systemd.

Звонок длиннее 60 минут попадает в список неудачных (`recording.too-long`) и не скачивается. Звонок без речи или с
одним смешанным каналом не получит расшифровку и будет выбран снова при следующем запуске: программа пока не запоминает
неудачи. Его можно исключить условием, например `NOT id:375`.

## ИИ-агент

Агент с терминалом, например Claude Code или Codex, запускает `beeline` сам. Ему нужна инструкция:

```sh
beeline skill install
```

Приложение без терминала, например Claude Desktop или Cursor, подключается к серверу MCP:

```sh
beeline work mcp add claude-code --allow-writes
beeline work mcp check
```

`beeline work mcp config` печатает настройку, которую можно вставить в другое приложение. Агент никогда не входит и не
выходит из профиля за вас. Текст звонка для агента только данные, а не команды.

## Если что-то не так

| Что видите | Что сделать |
|---|---|
| `profile work is not signed in` | Войдите: `beeline work session start`. |
| `Beeline refused the API token` | Ключ неверный или отозван. Возьмите новый в кабинете и войдите снова. |
| `the speech model gigaam-v3 is not on this computer` | Скачайте модель: `beeline models download gigaam-v3`. |
| `could not reach Beeline Cloud PBX` | Нет связи с Билайн. Проверьте интернет и запустите снова. |
| Звонков меньше, чем ожидали | Проверьте, что в АТС включена запись для этих менеджеров. |

Сообщения программы на английском. С `--json` каждая ошибка приходит с кодом, по которому скрипт может решить, что
делать дальше.

## Безопасность

- Ключ API уходит только в Билайн, в заголовке запроса. Ни одна команда, ошибка или журнал его не показывает.
- `beeline` только читает данные Билайн: он не может удалить запись или позвонить.
- В локальной базе лежат номера клиентов и имена менеджеров. Берегите её так же, как сами звонки.

О найденной уязвимости пишите на [hello@wirecat.dev](mailto:hello@wirecat.dev), не в открытые задачи.
